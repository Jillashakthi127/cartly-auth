# Cartly — Sign in & Sign up

Static e-commerce login and registration pages (HTML, CSS, vanilla JS), styled after the classic split-panel marketplace login.

- `index.html` — Login with email/mobile → OTP, or password login
- `signup.html` — Registration (name, mobile, email, password) → OTP → welcome
- Front-end only: validation and OTP steps are simulated; wire `app.js` to your auth API.

Hosted with GitHub Pages from the `main` branch root.
